页面上的模式

人类键盘操作；动作经 POST /action 交给桥执行，记录同样进榜。 本地启发式自动纯本地规则，页面自己发落点，不经过决策层：贪吃蛇 = 洪水填充保活 + 贪心靠近食物；方块 = Dellacherie 评分（业界经典权重）。用来对照和离线查看。 决策层驱动真正的玩法：主 Agent 调 decision_run 把 endpoint 指向桥。桥持有权威局面，每次把结构化局面 + 四个策略候选交给决策模型，模型选一个策略，桥按该策略执行（蛇连走 8 步 / 方块算一个落点），然后再问一次。页面不参与决策，只渲染。
实测（本机，同一种子）：决策粒度决定成绩。 让模型逐步选方向/落点 → 贪吃蛇 16 步 0 分就撞死、方块 600 分消 5 行就顶死； 让它只选策略、本地算走法 → 贪吃蛇 12 分 / 166 步 / 长度 15、 方块 55400 分 / 消 95 行 / 200 块没死。 这是 System-1 决策模型：擅长"从有限选项里选一个"，不擅长逐步决策，所以桥固定用策略粒度。 页面上的「最近一次落子」会显示它选了四个策略里的第几个，可以自己看。
